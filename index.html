01 POR QUE TECH DELAS?

Mais acesso.
Mais vozes.
Mais futuro.

O Tech Delas é uma atividade extensionista acadêmica que reúne informação e oportunidades para aproximar mais mulheres da tecnologia. Acreditamos que esse espaço precisa refletir a diversidade de quem faz parte dele.

Seja para explorar uma primeira linguagem de programação ou encontrar uma comunidade, cada passo conta.
